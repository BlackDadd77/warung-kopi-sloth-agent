# warung-kopi-sloth-agent
In my kampung Titi Gajah, the Warung Kopi WhatsApp group has 300+ messages daily. Pak Din shares tazkirah, Mat worries about his spinning coffee cup (a sign the Golden Vortex is coming), and Minah reminds everyone about two heirlooms: Quran and Sunnah
Scrolling is tiring. So I built a *Slow and Steady Agent*.


This local AI agent works overnight at 3 AM. It reads the chat export, transcribes voice notes in Kedah dialect using http://Whisper.cpp, and summarizes everything into one Kedah pantun using a 100% offline open-weight model - *Llama 3.2 3B via Ollama*.


In the morning, you get:

- A pantun ringkasan

- 3-point summary

- Nasihat from Gajah Putih Guardian (White Elephant)

- MP3 read by 3 cloned voices (Pak Din, Mat, Minah) via ElevenLabs/Bark


*Why it rewards laziness:* You literally do nothing. Export chat, sleep, wake up to wisdom. The poster shows Raja Titi Gajah with his White Elephant Guardian and the Golden Vortex tornado - plus our lazy mascot, Sloth wearing a Tanjak!


100% open-source, 100% local, 0% API cost. Privacy for kampung folks.
